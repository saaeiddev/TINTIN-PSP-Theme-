# TINTIN PSP Theme — candidate build

Creator: Amir Saeid Dehghan. This is an unofficial fan project, not a licensed release.

A PTF candidate and source assets are present. It was built with PTF Studio 1.0 and passed a tool round trip and independent structural checks. It has not been installed or rendered on physical PSP hardware or an emulator; universal and PSP Go compatibility therefore remain unverified. The previews are simulations. See `docs/TESTING.md` and `docs/CREDITS.md` for checks and limitations.

The wallpaper master is AI-generated raster art rather than a layered or vector source. The rights to distribute derivative Tintin artwork have not been established. A GitHub Release has not been created.
